# Кто Куда / СпортВместе

Адаптивный веб-прототип платформы совместных спортивных активностей (кейс Столото, ФСП). Помогает найти компанию для занятий спортом, посмотреть условия мероприятия и записаться или обсудить детали с организатором.

## Стек

- React 19 + TypeScript + Vite
- Tailwind CSS 4
- React Router, lucide-react
- Данные: seed + `localStorage` (ключ `sport-together-db`)
- Авторизация: email + пароль (SHA-256 hash в `accounts`, только для прототипа)

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`

## Учётная запись администратора

| Поле | Значение |
|------|----------|
| Email | `admin@kto-kuda.ru` |
| Пароль | `Admin2026!` |

После входа доступна страница `/admin` (роль `admin`). Пароль в storage не хранится — только хеш.

## Регистрация и вход

- `/register` — новый пользователь (роль `user`), автоматический вход после регистрации
- `/login` — вход по email и паролю
- В профиле — **«Выйти из аккаунта»**

Без входа доступны лента, каталог и просмотр событий. Для записи на событие, «Мои события», создания события и отправки сообщений в обсуждении нужен вход.

Демо-персонажи (Витя, Аня и др.) остаются в данных событий, но **войти под ними нельзя** — только через зарегистрированные аккаунты.

В профиле — «Сбросить демо-данные» для возврата к seed (сбрасывает сессию и данные).

## Что сохраняется локально

Учётные записи, сессия, записи на события, заявки, комментарии, избранное, лайки, созданные события и новые виды спорта.

## Сценарии кейса

| # | Сценарий | MVP | Фаза 2 |
|---|----------|-----|--------|
| 1 | Создание мероприятия + свой вид спорта | Да (`/create-event`, после входа) | API |
| 2 | Допуск организации | Демо-данные, заглушка `/org` | Админ + API |
| 3 | Свободное присоединение | Да | API |
| 4 | Участие по заявке | Да | API |
| 5 | Обсуждение | Да (`/events/:id/discussion`) | API |
| 6 | Снятие с публикации | Демо-событие `ev-unpublished` | Админ UI |

## Структура

- `src/app/` — роутинг, shell, контекст данных
- `src/data/auth.ts`, `authRepository.ts` — хеш пароля, login/register/logout
- `src/components/` — UI-компоненты, `RequireAuth`
- `src/pages/` — экраны
- `public/images/` — изображения для карточек

## Адаптивность

- Мобильные: нижняя навигация (5 пунктов)
- Desktop (≥768px): боковое меню, двухколоночная карточка события
